# твой казак — сайт-портфолио

Версия **0.4.0**. Публичный бренд — **«твой казак»**. `void-site` остаётся названием технического GitHub-репозитория, не публичным брендом.

Светлый минималистичный сайт: главная, концептуальные кейсы, услуги под задачи бизнеса, личная авторская ИИ-система, автор (Данил, 4+ года в дизайне), личный Telegram и канал. Все незавершённые кейсы отмечены; ни один не представлен как готовый коммерческий результат.

## Разработка

Требуется Node.js 22+. Внешних npm-зависимостей нет.

```bash
npm run check      # unit tests, сборка, проверка страниц/ссылок
npm run preview    # http://127.0.0.1:4173
```

Сборка готового сайта — в папке `dist/`. Автоматические проверки запускаются в GitHub Actions на каждом обновлении `main`.

## Размещение в Yandex Cloud

Production Object Storage bucket: `tvoykazak`.

**Простой ручной способ:** скачать GitHub Actions артефакт `void-site` из последнего успешного запуска `VOID — проверки и сборка`, распаковать и загрузить **содержимое** сборки в бакет Object Storage с сохранением каталогов `assets/`, `cases/`, `privacy/` и файлов `index.html`, `404.html`, `robots.txt`. Не загружать исходники `src/` или весь архив ZIP как объект. Отдельный сценарий автоматического деплоя в Yandex Cloud имеется, но необязателен.

Проверить в бакете разрешения на публичное чтение объектов и статический веб-хостинг: index `index.html`, error `404.html`. Технический адрес предполагается `https://tvoykazak.website.yandexcloud.net/`; доступность нужно проверить после каждой загрузки. Дополнительные инструкции: [docs/DEPLOY-YANDEX.md](docs/DEPLOY-YANDEX.md).

## Структура

- `content/site.json` — публичный бренд, ссылки Telegram, описание, будущий HTTPS-адрес.
- `content/projects.json` — кейсы, публикация только со статусом `published` и проверенными разделами.
- `src/build.mjs` — шаблоны страниц + правила типографики (неразрывные пробелы после коротких слов).
- `public/assets` — стили, клиентский JavaScript, фавикон.
- `docs/CONTENT-RULES.md` — утверждённые правила публичного сайта.
- `tests/` и `scripts/check-dist.mjs` — автоматические проверки.

## Контакты и честные ограничения

- Все CTA «Обсудить проект» и «Написать о проекте» ведут в личный Telegram: https://t.me/tvoykazak.
- Канал: https://t.me/kazakblog.
- Формы нет, заявка не записывается в CRM. Стандартная Telegram-ссылка **не передаёт UTM в личную переписку**. Сбор статистики источников возможен после отдельной настройки аналитики.
- Внешняя аналитика пока не подключена. Поисковая индексация закрыта, пока `content/site.json.siteUrl` пустой (сборка создаёт `robots.txt: Disallow: /`).
- Собственная ИИ-система развивается; не приписываем ей неподтверждённые результаты или полную автоматизацию.
- На сайте в качестве основного направления используются **цифровые решения для бизнеса**, а не продажа «просто сайтов».

Публикация на хостинг не выполняется автоматически после каждого изменения. Для видимого обновления нужно загрузить новую сборку в Yandex Cloud.
