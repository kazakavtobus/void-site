# VOID SALES / VOID GROWTH — схема интеграции

## Назначение

Привязать обращение к источнику, не нарушая приватность посетителя и не создавая ложное ощущение работающей CRM.

## v0.1 (работает в этой сборке)

- Ссылки формата `?utm_source=tiktok&utm_medium=shorts&utm_campaign=launch` или `?ref=telegram_channel`.
- Значения `utm_source`, `utm_medium`, `utm_campaign`, `utm_content`, `utm_term`, `ref` (до 120 безопасных символов) сохраняются в `sessionStorage` в течение вкладки.
- При нажатии на CTA email создаётся черновик письма с UTM-полями и местом для задачи.
- Пользователь отправляет письмо самостоятельно; внешних трекеров и автоматической отправки лидов нет.
- JS событие `void:track` (`contact_click`) готово для будущего подключения Яндекс Метрики.

## v0.2 (нужны инфраструктура, проверка и согласование)

### API

`POST /api/leads` с JSON `{ name, contact, description, consent, source, medium, campaign, content, term, ref, landing_page }`.

Обработка **только на сервере в РФ** с подтвержденным правовым режимом: HTTPS, ограничение размеров, валидация полей, антиспам (honeypot, rate limiting), CSRF/Origin, логирование ошибок без PII, секреты в server env, не в репозитории. Данные хранить только необходимый срок в согласованном хранилище. Политика обработки данных, сведения об операторе и явно осмысленное согласие — до запуска формы.

### Взаимодействие с SALES

Статусный жизненный цикл: `new → qualified → contacted → proposal → won/lost`. Поля: `lead_id`, дата UTC, канал, ссылка первого входа, имя/контакт (с явным согласием), запрос, источник, статус, ответственный, следующая задача. Канал уведомления — email либо закрытый Telegram-бот; ключи только на сервере. Автоматическая отправка/спам исходящих сообщений не делается.

### Взаимодействие с GROWTH

UTM справочник: `utm_source` (`tiktok`, `youtube`, `vk`, `telegram`, `direct`), `utm_medium` (`shorts`, `reels`, `clips`, `post`, `bio`, `referral`), `utm_campaign` (`launch_2026`, конкретная серия). Отчёт: посещения по каналам, клики на CTA, отправленные заявки, квалифицированные заявки и выигранные сделки — только на основе реально подключённых источников, без выдуманных конверсий.

### Аналитика и согласие

Яндекс Метрика может использоваться после публикации политики и проверки необходимых требований для применимого режима аналитики и согласия. Скрипт и ID нельзя включать до решения об обработке данных. Блокировщики аналитики не должны ломать сайт или форму.

## Открытые решения

Точный публичный email, Telegram username, адрес домена, провайдер hosting/API и CRM хранилище, реквизиты оператора персональных данных.
