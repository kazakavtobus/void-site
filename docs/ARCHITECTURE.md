# VOID BUILD — архитектура v0.3

Дата: 22.10.2026 · Статус: **Пилот**.

## Ключевое решение

- Статическая генерация HTML + CSS + JS на Node.js 22, без внешних зависимостей.
- Для блога и многих кейсов этого хватает. React/Next/Astro вводим лишь если появляется реальная задача.
- GitHub хранит исходники, GitHub Actions проверяет каждый push/PR, `dist/` генерируется во время CI.
- Единственный production-хостинг для первого этапа: Yandex Cloud Object Storage. GitHub Pages сознательно не используется.
- Публикация через ручной GitHub workflow после отдельной настройки доступа к выделенному бакету.

## Структура

- `content/site.json` — публичные контакты и HTTPS-домен.
- `content/projects.json` — статус и метаданные кейсов. Черновики не порождают страницы.
- `src/build.mjs` — шаблоны, страницы, проверка данных и sitemap.
- `public/assets` — интерфейс и JS навигации / локальной UTM-атрибуции.
- `scripts/check-dist.mjs` — структурная проверка сгенерированной сборки.
- `.github/workflows/ci.yml` — проверка на push/PR и артефакт сборки.
- `.github/workflows/publish-yandex.yml` — публикация только по ручному подтверждению.

## Контент и дизайн

VOID светлый, с прозрачной навигацией, минимальным количеством эффектов, ясной иерархией и однозначным CTA. Не утверждать экспериментальные работы как коммерческие. Кейсы `planned` / `draft` не кликабельны, `published` создают страницу по slug.

## Приём обращений

Текущая ссылка — email с локальной атрибуцией UTM в теме/теле письма; серверной формы, автоматического сбора лидов и CRM пока нет. Для формы потребуется отдельный backend с правовыми и безопасностными проверками.
