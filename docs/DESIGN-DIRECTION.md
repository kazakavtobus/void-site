# VOID — дизайн-направление v2 / 22.10.2026

Утверждено по вводным владельца проекта: светлый, очень простой сайт, вдохновлённый ясностью интерфейсов Apple. Стеклянные элементы деликатно — в навигации и акцентных поверхностях. Не копировать чужую айдентику и не строить весь сайт из glassmorphism-карточек.

## Приоритеты
1. С первых секунд ясно, кто автор (Данил, веб-дизайнер и разработчик), чем занимается и куда нажать.
2. Кейсы — сразу после первого экрана. Только реальные завершённые или честно помеченные незавершённые концепты.
3. Простые блоки услуг, обо мне и связи; одна основная цель — обсудить задачу.
4. Белые поверхности, светло-серый фон, системная типографика, лёгкий синий акцент, скругления, воздух. Минимальные анимации без зависимости функциональности от них.
5. Фотографию автора добавлять только после получения согласованного реального изображения; пока используется типографический символ.

## Токены
- background: #f8f9fb; paper: #fff; ink: #16171a; secondary: #6e737d; blue: #2c66e7.
- container 1180px; gutters 20–56px; cards radius 24px; hero typography up to 90px.
- glass header uses translucent white, blur, subtle line and shadow with readable solid fallback.

## Ограничения релиза
Не заявлять о рабочей серверной форме, если реализован только mailto. Не показывать кейсы как опубликованные до смены статуса `published` и проверки страницы. Не считать типографический символ фотографией владельца. Не подключать аналитику до согласования обработки данных.
