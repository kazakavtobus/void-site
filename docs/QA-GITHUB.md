# QA — подготовка GitHub + Yandex Cloud

Дата: 22.10.2026. Среда: Node.js 22.16.0, Linux, локальная файловая система.

Проверки выполнять заново после любых изменений:

```bash
npm run check
```

Скрипт выполняет unit-тесты, строит HTML и проверяет все внутренние ссылки. Обязательно проверить результаты CI после первого push на GitHub.

Ограничения: workflow GitHub Actions пока не запускался, бакет Yandex Cloud не создан, публичный HTTPS-домен отсутствует. Приём писем / аналитика / CRM и доступность из России требуют реальной проверки после публикации.

## Фактический локальный прогон (22.10.2026)

- `npm run check`: **успешно**, 8/8 unit-тестов, собраны 4 HTML-страницы (включая `404.html`), 0 опубликованных кейсов.
- `npm run smoke`: **успешно**, проверено 59 ссылок на внутренние статические ресурсы/страницы.
- `node --check`: **успешно** для клиентского JS, сборщика, preview-сервера и smoke-скрипта.
- Разбор двух GitHub Actions YAML файлов: **успешно** локальным YAML-парсером (это не фактический запуск GitHub Actions).
- HTTP-проверка локального сервера: **200** для `/`, `/cases/`, `/privacy/`, `/404.html`, `/assets/site.css`, `/assets/site.js`, `/assets/favicon.svg`, `/robots.txt`; **404** для отсутствующего пути.
- Не проверено: GitHub Actions в реальном репозитории, Yandex Cloud, домен/HTTPS, доступность с сетей РФ, доставка email.
