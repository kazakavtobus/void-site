# «твой казак» — статус v0.4 от 22.10.2026

**Выполнено:** публичный ребрендинг VOID → «твой казак» без переименования технического GitHub-репозитория, позиционирование через задачи бизнеса, корректировка опыта (более 4 лет дизайна), отдельный блок о собственной ИИ-системе и личной ответственности, контакты через Telegram, ссылка на канал, неразрывные пробелы для коротких служебных слов.

**Проверено локально:** Node.js unit-тесты, генерация 4 статических страниц, наличие локальных ссылок и Telegram-адресов, отсутствие старого бренда в HTML. Результаты см. GitHub Actions после загрузки коммита.

**Размещение:** `tvoykazak` в Yandex Cloud Object Storage. На дату этого файла новый релиз **ещё не загружен в бакет**. Для ручной публикации нужна свежая сборка `dist/`.

**Не подключено:** рабочая серверная форма, CRM, аналитика, автоматическая передача UTM в Telegram. Все неподтверждённые кейсы остаются черновиками.
